# アラームアプリ

シンプルなWebベースのアラームアプリです。

## 機能

- **現在時刻の表示** — 秒単位でリアルタイム更新
- **アラーム追加** — 時刻とラベルを設定して追加
- **複数アラーム** — 複数のアラームを一覧管理
- **ON/OFFトグル** — アラームを個別に有効/無効切り替え
- **アラーム削除** — 不要なアラームを削除
- **アラーム通知** — 設定時刻になるとモーダルで通知＋アラーム音
- **スヌーズ** — 5分後に再アラーム
- **データ永続化** — `localStorage` に保存、リロード後も維持

## 使い方

1. `index.html` をブラウザで開く
2. 時刻を選択し、必要であればラベルを入力して「追加」をクリック
3. 設定した時刻になると音とモーダルで通知
4. 「停止」または「スヌーズ（5分）」を選択

## 技術スタック

- HTML5
- CSS3（Glassmorphism デザイン）
- Vanilla JavaScript
- Web Audio API（アラーム音）
- localStorage（データ永続化）

## ブラウザ要件

最新の Chrome / Firefox / Safari / Edge で動作します。
